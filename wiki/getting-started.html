Erste Schritte

Alles was du wissen musst um loszulegen

1. Server beitreten

Jeder kann ohne Whitelist joinen. So verbindest du dich:

  1. Starte Minecraft Java Edition oder Bedrock Edition
  2. Gehe zu Multiplayer
  3. Klicke auf Server hinzufügen
  4. Gib als Server-Adresse pelmeni.cc ein
  5. Verbinden – und los geht's!
ℹ️

Unterstützte Versionen: Java ab 1.9 und Bedrock Edition. Details auf der Java & Bedrock-Seite.

2. Erste Schritte auf dem Server

Nach dem ersten Login empfehlen wir:

  • Regeln lesen – damit du weißt was erlaubt ist
  • Einen Bauplatz suchen und erkunden
  • Im Chat andere Spieler begrüßen
  • /help eingeben um alle verfügbaren Befehle zu sehen

3. Wichtige Befehle für den Anfang

BefehlFunktion
/helpAlle verfügbaren Befehle anzeigen
/tell <Spieler> <Nachricht>Privatnachricht senden
/pvptogglePvP an- oder ausschalten
/axgraves listDeine Gräber anzeigen

Alle Befehle findest du in der vollständigen Befehlsreferenz.

4. Hilfe & Support

Bei Fragen oder Problemen schau in die FAQ oder melde dich im Discord.

⚠️

Bitte lese die Serverregeln bevor du anfängst zu spielen. Unwissenheit schützt nicht vor Konsequenzen.
