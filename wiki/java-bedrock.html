Java & Bedrock

Cross-Play zwischen Java und Bedrock Edition

Der Pelmeni SMP unterstützt sowohl Java Edition als auch Bedrock Edition. Spieler beider Plattformen können zusammen auf demselben Server spielen.

Unterstützte Versionen

  • Java Edition: alle Versionen ab 1.9
  • Bedrock Edition: aktuelle Version empfohlen (Windows, Mobile, Konsole)

Verbinden

Die Server-Adresse ist für beide Editionen gleich:

pelmeni.cc
⚠️

Bedrock-Spieler haben einen Stern (*) vor ihrem Namen im Chat. Manche Java-exklusiven Features (z.B. bestimmte Tastenkürzel) stehen Bedrock-Spielern nicht zur Verfügung.
